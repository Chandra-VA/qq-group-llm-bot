# 图片与表情包素材

把 JPEG、PNG、GIF 或 WebP 放进 `common/`，用有意义的文件名，例如 `绷不住了_笑哭.gif`。机器人自动读取文件名作为素材标签，新增文件后无需重启。这里的图片可在所有白名单群使用。

在群里发一张图片，同时说 `/ai 收藏表情 绷不住了`，或引用同群的一张图片再发这个指令，即可收藏。图片存放于 `groups/群号/`，仅在原群使用。正常聊天不自动保存图片。

- `/ai 素材库`：列出当前群可用素材及 ID。
- `/ai 发图 绷不住了`：按精确名称或 ID 发图，不调用大模型。
- `/ai 删除表情 绷不住了`：删除本群收藏，公共素材在本机文件夹里管理。
- `/ai 发表情 呲牙`：直接发 QQ 自带表情，不调用大模型。

也可以自然地要求“大肥鱼来个表情包”，模型会结合话题挑选素材。素材为空时仍可使用 QQ 自带表情。

单张素材默认最多 6 MiB，每群最多收藏 100 张，模型每轮最多看到 40 项标签；模型只拿到素材 ID、标签和种类，原始图片由本机发送给 QQ。收藏的 GIF 保留原文件字节，不转成静态图。
